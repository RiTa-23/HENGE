# 最適化練習の共通語彙リスト

`apps/backend/src/generation/vocabulary.generated.ts` の作り方。最適化ごとの語彙は、作成時に
このリストから読みの部分一致で選ぶ（`apps/backend/src/generation/vocabulary.ts`）。設計は
`docs/05-generation.md` の「最適化練習の語彙」。

**作り直すのは、選び方か NG 語（`packages/shared/src/generation/ng-words.ts`）を変えたときだけ。**
既存の最適化の語彙は作成時に D1 へ保存してあるので、作り直しても自動では変わらない。

## 手順

```sh
# 1. 素材（UniDic cwj-3.1.1 の lex_3_1.csv、233MB）。辞書リポジトリ RiTa-23/unidic-cwj-trim と同じもの
curl -fsSLO https://clrd.ninjal.ac.jp/unidic_archive/cwj/3.1.1/unidic-cwj-3.1.1-full/lex_3_1.csv
echo "887bc6dc865d7b839193d03bda50c50f1a36926cb84b567c39ac758da0b8d87d  lex_3_1.csv" | sha256sum -c

# 2. wordfreq（頻度表は同梱）
python3 -m venv .venv && .venv/bin/pip install -r scripts/vocabulary/requirements.txt

# 3. 生成（数秒）
.venv/bin/python scripts/vocabulary/build.py lex_3_1.csv
```

`lex_3_1.csv` と `.venv` はリポジトリに入れない。

## 選び方

| 手順 | 内容 | 理由 |
|---|---|---|
| 品詞 | 名詞-普通名詞、動詞（一般・非自立可能）、形容詞（一般・非自立可能）、形状詞-一般、副詞 | 固有名詞は外す。「出来る」「来る」「無い」「良い」は非自立可能にある |
| 見出しに畳む | 語彙素ごとに1件。表記は書字形基本形、読みは仮名形基本形 | 活用形を別々に持つと、語数の割に同じ語が繰り返し出る。断片（「座ら」）を渡すと文も不自然になる |
| 代表の表記 | 語彙素の標準表記 | 頻度で選ぶと「座る」の語彙素に含まれる「居る」を取る |
| zipf 2.0 以上 | wordfreq の頻度（対数）。2 は「氷河・雑穀・遠ざかる」くらい | 最低100語のとき、頻度表に載る語を全部使っても2.0で絞っても、作れる連接は同じだった。切る1.6万語はほぼ珍しい語 |
| NG 語を外す | 生成後の検査（`containsNgWord`）と同じ照合 | 渡しても必ず落ちる |
| 1文字の漢字を外す | 「年」「方」「人」など | 読みが紛れる（下の実測） |
| 読みを1つに絞る | 同じ表記の読みは、UniDic 全体（外した品詞も含む）で語コストが最も低いものだけ | 頻度は表記単位なので、「強い=じい」「生活=らいふ」のような珍しい読みにも普通の読みの頻度が付く |

### 実測（2026-10-24）

**読みの紛れ。** 読みの正解付きの Web 文コーパス KWDLC で、「その表記が狙った読みで使われる割合」を数えた。

| 規則 | 語数 | 渡される語が狙いの読みで使われる割合 |
|---|---|---|
| 今の規則から「1文字の漢字」「読みを1つに絞る」を抜いたもの | 36,748 | 0.88 |
| 今の規則 | 32,808（表記と読みの重複をまとめると 32,145） | 0.99 |

1文字の漢字は、狙いの読みで使われる割合が半分未満のものが43%あった（年=とし 2%、方=ほう 8%、人=にん 20%）。2文字以上では7%。

**連接ごとの語数。** 1文字の清音・濁音・半濁音・拗音すべてと2〜3文字の代表例の118連接で、1000語以上 40・100〜999語 56・100語未満 22（作れない。拗音の大半、を・ぢ・ゔ、でき・ぬの・ぺん）。プリセットの ざ 500・き 3,504・で 611。下限に近いのは ひょう 107。

**大きさ。** 約78万バイト（gzip 後 約30万バイト）。
