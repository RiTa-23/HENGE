# 最適化練習の共通語彙リスト

`apps/backend/src/generation/vocabulary.generated.ts` の作り方。最適化ごとの語彙は、作成時に
このリストから読みの部分一致で選ぶ（`apps/backend/src/generation/vocabulary.ts`）。設計は
`docs/05-generation.md` の「最適化練習の語彙」。

**作り直すのは、選び方・NG 語（`packages/shared/src/generation/ng-words.ts`）・外す語（`excluded.tsv`）を変えたときだけ。**
既存の最適化の語彙は作成時に D1 へ保存してあるので、作り直しても自動では変わらない。

## 手順

```sh
# 1. 素材（UniDic cwj-3.1.1 の lex_3_1.csv、233MB）。辞書リポジトリ RiTa-23/unidic-cwj-trim と同じもの
curl -fsSLO https://clrd.ninjal.ac.jp/unidic_archive/cwj/3.1.1/unidic-cwj-3.1.1-full/lex_3_1.csv
echo "887bc6dc865d7b839193d03bda50c50f1a36926cb84b567c39ac758da0b8d87d  lex_3_1.csv" | sha256sum -c

# 2. wordfreq（頻度表は同梱）
python3 -m venv .venv && .venv/bin/pip install -r scripts/vocabulary/requirements.txt

# 3. 生成（数秒）
.venv/bin/python scripts/vocabulary/build.py lex_3_1.csv
```

`lex_3_1.csv` と `.venv` はリポジトリに入れない。

## 選び方

| 手順 | 内容 | 理由 |
|---|---|---|
| 品詞 | 名詞-普通名詞、動詞（一般・非自立可能）、形容詞（一般・非自立可能）、形状詞-一般、副詞 | 固有名詞は外す。「出来る」「来る」「無い」「良い」は非自立可能にある |
| 見出しに畳む | 語彙素ごとに1件。表記は書字形基本形、読みは仮名形基本形 | 活用形を別々に持つと、語数の割に同じ語が繰り返し出る。断片（「座ら」）を渡すと文も不自然になる |
| 代表の表記 | 語彙素の標準表記 | 頻度で選ぶと「座る」の語彙素に含まれる「居る」を取る |
| zipf 2.0 以上 | wordfreq の頻度（対数）。2 は「氷河・雑穀・遠ざかる」くらい | 最低100語のとき、頻度表に載る語を全部使っても2.0で絞っても、作れる連接は同じだった。切る1.6万語はほぼ珍しい語 |
| NG 語を外す | 生成後の検査（`containsNgWord`）と同じ照合 | 渡しても必ず落ちる |
| 1文字の語を外す | 漢字の「年」「方」「人」、かなの「ど」「ほ」など | 漢字は読みが紛れる（下の実測）。かなは語の断片 |
| 断片を外す | 「っ」で終わる語（「がっ」「ぶっ」）、ひらがなだけの2文字以下の語（「たん」「きん」「うる」） | UniDic では擬音語の副詞として表記の持ち主になっているので、下の規則では外れない。頻度は別の語の断片から付く |
| 表記の持ち主に絞る | その表記で書かれる行（外した品詞・活用形も含む UniDic 全体）で語コストが最も低い行が、その語彙素のものだけ。その行が助詞・助動詞・感動詞・接頭辞・接尾辞なら外す（連体詞・接続詞は外さない。「同じ」「一方」） | 頻度は表記単位なので、別の語の頻度が付く。「強い=じい」「生活=らいふ」のような珍しい読み、「ます」（升。助動詞の頻度）・「で」「と」（助詞）・「だっ」（「だった」）・「行き」（「行く」の活用形）が上位に来ていた |
| 手で外す | `excluded.tsv` の「表記・読み」の組（下の「外す語の判定」） | 語の断片・意味の取りにくい語・お題に向かない語・読み違いのうち、UniDic の品詞や頻度では拾えないもの |

### 実測（2026-10-24）

**読みの紛れ。** 読みの正解付きの Web 文コーパス KWDLC で、「その表記が狙った読みで使われる割合」を数えた。

| 規則 | 語数 | 渡される語が狙いの読みで使われる割合 |
|---|---|---|
| 当時の規則から「1文字の漢字」「読みを1つに絞る」を抜いたもの | 36,748 | 0.88 |
| 当時の規則（「表記の持ち主に絞る」の前身の「読みを1つに絞る」まで） | 32,808（表記と読みの重複をまとめると 32,145） | 0.99 |

2026-10-25 に「表記の持ち主に絞る」「断片を外す」と、1文字のかなを外す規則を足し、30,765語にした（KWDLC では測り直していない。
外れた1,382語は、上記の機能語・活用形・断片と、持ち主が固有名詞の「太郎」「山田」など）。

1文字の漢字は、狙いの読みで使われる割合が半分未満のものが43%あった（年=とし 2%、方=ほう 8%、人=にん 20%）。2文字以上では7%。

**連接ごとの語数**（手で語を外す前の値。外した後は下の「外す語の判定」）。1文字の清音・濁音・半濁音・拗音すべてと2〜3文字の代表例の118連接で、1000語以上 40・100〜999語 56・100語未満 22（作れない。拗音の大半、を・ぢ・ゔ、でき・ぬの・ぺん）。2026-10-25 の作り直しで、下限（100語）をまたいで入れ替わった連接は無い（1文字のかな・拗音すべてと でき・ぬの・ぺん・ひょう の109連接で数え直した）。プリセットは ざ 483・き 3,361・で 594。下限に近いのは ひょう 107・づ 108・ひょ 110。

**大きさ。** 約78万バイト（gzip 後 約30万バイト）。

## 外す語の判定

`excluded.tsv` は 1行1語の「表記<TAB>読み<TAB>理由」。規則（上の表）を通った 30,765語を、2026-10-25 に1語ずつ目で
判定して 2,017語を入れた（残りは 28,748語）。`build.py` は該当する語がもう無い行を標準エラーに出す（規則を変えて
その語が外れた・表記が変わったときは、行を消すか判定し直す）。

| 理由 | 語数 | 何を外すか | 例 |
|---|---|---|---|
| 断片 | 1,298 | 単独では使わない語。動詞の連用形だけの名詞、連濁した読み、外来語の切れ端、略語の切れ端 | 取り掛かり・吸い取り・日和=びより・ザキ・アスタ・財経 |
| 難解 | 440 | 意味の取りにくい語、ごく狭い分野の専門語、知らない人が多い固有名詞・俗語 | ハドロン・リバタリアニズム・システイン・アルディージャ・上地 |
| 不向き | 109 | 医療・性の周辺の語、差別語 | 座薬・ボンデージ・排尿・月経 |
| 読み違い | 170 | 普通は別の読みをする表記（その読みでは文の中で読み違える） | 鐘楼=しゅうろう・胡坐=こざ・箪笥=だんす |

**外さないもの。** 俗語・ネット用語（「ドキュン」「コテハン」「ダチ」「ドキッ」）、固有名詞（商品名・チーム名・作品名を
含む。「ドンペリ」「ポケモン」「ジャイアンツ」）は、知られたものなら残す。暴力・死に関わる語（「斬首」「獄死」）と、
硬い語・古い語（「逡巡」「烏帽子」）も残す。

**連接ごとの語数の変化。** 上の118連接で、1000語以上 37・100〜999語 58・100語未満 23。下限をまたいだのは づ だけ
（108→96。作れなくなる）。プリセットは ざ 458・き 3,204・で 542。下限に近いのは ひょう 104・ひょ 107。
