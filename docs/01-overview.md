# HENGE とは

お題が毎回変わることで「慣れ」が生じない、日本語タイピング練習ツール。

## コアループ

1. ユーザーがテーマ（例:「忍びの心得」）を選ぶ、または作る
2. そのテーマのお題15問が出題される
3. 打ち終わると結果（打鍵速度・ミス数・正確率）が出る
4. もう一度遊ぶと、**前回とは違う15問**が出る

同じお題を繰り返さないため、暗記による有利不利が発生しない。

## 3つの特徴

- **待ち時間ゼロ**: プレイ中に裏で次回分を生成しておく。他ユーザーが生成済みのテーマは即座に遊べる
- **好きなテーマで練習できる**: お題は運営が用意せず、ユーザー指定のテーマからAIが生成する
- **「〇〇を含む」最適化モード**: 特定のかな（例:「ざ」）を含む文章だけを生成し、運指の弱点を毎回違う文脈で練習できる

## MVPのスコープ

### 実装する

- お題プールでのタイピングプレイ（匿名・ログイン問わず）
- テーマ指定での新規お題生成（Workers AI）
- 「〇〇を含む」最適化モード
- ローマ字入力の柔軟性（`fu`/`hu` など複数表記の受理）
- Google認証（Better Auth）
- 忍者・古風UI
- 管理画面（テーマ削除・ユーザー一覧）

### 実装しない

課金（Stripe）、対戦機能、ブラウザLLM（Gemini Nano）、マイページ、お気に入り、スコアの保存・履歴、OGP画像の動的生成。

**これらに関するコードを先回りで書かない。** 例えば `user` テーブルに `plan` カラムを足す、といった準備も不要。

## 遊びの単位

- 1プレイ = 15問
- お題1問の長さ = **ローマ字10〜40打鍵**
- 制限時間なし（時間制限はミスを誘発するため採用しない）
- 画面にキーボードを表示し、次に打つキーをハイライトする
